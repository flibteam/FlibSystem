# FlibSystem
Оптимизация Windows 10/11: твики реестра с мгновенным применением, полная инфа о системе, диспетчер задач с мониторингом CPU/RAM/сети/диска/GPU, автозагрузка, очистка, управление приложениями UWP и бэкап реестра. Понятный интерфейс в стиле macOS — всё в один клик. Присоединяйтесь к разработке и поддержите проект на DonationAlerts!
